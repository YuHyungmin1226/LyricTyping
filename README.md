# 🎵 LyricTyping (노래 가사 타자 연습)

좋아하는 노래 가사를 직접 추가하고 따라 치면서 **실시간 분당 타수(CPM)**, **평균 분당 타수**, **정확도**를 정밀하게 측정하고 기록할 수 있는 웹 기반 타자 연습 프로그램입니다.  
별도의 서버나 설치 과정 없이 `index.html` 파일을 브라우저에서 열기만 하면 즉시 동작합니다.

---

## ✨ 주요 기능

1. **정밀한 한글/영문 타수 측정 엔진**
   - **한글 자소 분리 계산:** 완성형 한글(`가`~`힣`)의 초성·중성·종성을 분해하여 실제 타건 횟수를 계산합니다. 복합 모음(`ㅘ`, `ㅝ`, `ㅢ` 등)과 겹받침(`ㄳ`, `ㄺ`, `ㅄ` 등)의 2타 가중치까지 한컴타자연습 기준과 동일하게 반영합니다.
   - **한글 IME 조합 실시간 대응:** 글자를 조합하는 중(`compositionstart` ~ `compositionend`)에도 오타로 잘못 판정하지 않고 자연스럽게 타수를 계산합니다.
   - **고해상도 타이머 측정:** `performance.now()`를 사용하여 밀리초 단위로 **실시간 타수(현재 줄/최근 속도)**와 **전체 평균 분당 타수(CPM)**를 0.1초 주기로 갱신합니다.

2. **노래 가사 자유로운 관리 (추가 · 수정 · 삭제)**
   - 언제든 원하는 노래의 제목, 아티스트, 분류 태그와 가사를 추가하거나 수정·삭제할 수 있습니다.
   - 로컬 `.txt` 텍스트 파일을 불러와 즉시 노래 가사로 등록할 수 있습니다.
   - 가사 입력 시 총 줄 수와 예상 총 타수를 실시간으로 미리 계산해 보여줍니다.

3. **편리한 타자 연습 스테이지**
   - **이전 줄 / 현재 줄 / 다음 줄 / 이어지는 가사**를 한눈에 보여주는 줄 단위 연습 인터페이스를 제공합니다.
   - 글자별 정타(하늘색), 오타(붉은색 밑줄), 현재 입력 위치(초록색 언더바)가 실시간으로 하이라이트됩니다.
   - **자동 줄바꿈 옵션** (줄 끝까지 입력 시 자동 이동 또는 `Enter`/`Space` 키 이동) 및 **Web Audio API 기반 타건음 효과**를 지원합니다.

4. **연습 기록 자동 저장 및 데이터 백업/복원**
   - 한 곡을 끝까지 완주하면 **평균 타수, 최고 순간 타수, 정확도, 소요 시간**이 자동으로 기록되며 곡별 최고 기록(`🏆 최고 타수`)이 표시됩니다.
   - 모든 가사 데이터와 연습 기록은 브라우저 `localStorage`에 자동 보존되며, **`내보내기(백업)` / `불러오기`** 기능으로 `.json` 파일로 언제든 백업 및 복원할 수 있습니다.

## 🚀 실행 방법

1. 저장소를 클론하거나 다운로드합니다.
   ```bash
   git clone https://github.com/YuHyungmin1226/LyricTyping.git
   ```
2. 폴더 내의 [`index.html`](./index.html) 파일을 더블클릭하여 웹 브라우저(Chrome, Edge 등)에서 바로 실행합니다.
